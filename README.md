# Компас

Открытый Android-проект на Kotlin. Пользователь выбирает приложения в списке, сам включает службу доступности в системных настройках, а служба возвращает на главный экран при появлении выбранного пакета. Нет Device Admin, скрытия приложения, блокировки Settings или запрета удаления.

## Сборка

1. Откройте папку проекта в Android Studio с JDK 17 и Android SDK Platform 36.
2. Gradle wrapper в проект не включён: при необходимости выполните `gradle wrapper --gradle-version 9.6.0` или укажите Gradle 9.6.0 в Android Studio. Дождитесь Gradle Sync. Проект использует Android Gradle Plugin 9.5.0 и встроенную Kotlin-поддержку AGP 9+.
3. Соберите и установите приложение на свой Android-телефон.
4. В «Компасе» отметьте приложения.
5. Нажмите «Открыть настройки службы доступности», включите «Компас: блокировка выбранных приложений» и подтвердите системное предупреждение.

Показаны приложения с launcher-ярлыками, кроме домашнего лаунчера, «Настроек», SystemUI и самого «Компаса»: их блокировка зациклила бы телефон на главном экране и не дала бы выключить службу. Служба получает только уведомления о смене окна, не запрашивает содержимое экрана и не читает нажатия. Android может доставлять события с небольшой задержкой; это не гарантирует блокировку до первого кадра на каждом устройстве. Чтобы остановить блокировку, выключите службу в настройках доступности или снимите отметки в приложении.

**Android 13+ и APK не из магазина.** Если переключатель службы неактивен («Ограниченная настройка»), откройте Настройки → Приложения → Компас → меню ⋮ → «Разрешить ограниченные настройки», затем снова включите службу.

## Сборка APK через GitHub Actions

В проект добавлен workflow `.github/workflows/build-apk.yml`. Он собирает отладочный APK при push, pull request или ручном запуске.

1. Создайте пустой репозиторий на GitHub.
2. Распакуйте архив и загрузите **содержимое папки проекта** в корень репозитория, включая скрытую папку `.github`.
3. Откройте вкладку **Actions**. После push запустится задача **Build Android APK**; при необходимости используйте **Run workflow**.
4. Когда задача завершится успешно, откройте её страницу, найдите раздел **Artifacts** и скачайте `kompas-debug-apk`. Внутри будет `app-debug.apk`.

Workflow использует JDK 17, Android SDK Platform 36, Android Gradle Plugin 9.5.0 и Gradle 9.6.0. Здесь подготовлен исходный проект и CI-файл; фактическая сборка должна быть запущена в GitHub Actions.
